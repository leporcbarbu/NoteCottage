## Bug Fixes Discovered & Fixed

### 1. Note Permission Security
**Issue:** Notes without folders were public to all users
**Fix:** Notes without folders are now private to their creator
**Impact:** Better privacy and security

### 2. Data Loss on Folder Deletion
**Issue:** Deleting a folder CASCADE deleted all notes and subfolders
**Fix:** Folder deletion now moves notes/subfolders to root level
**Impact:** Prevents accidental data loss

### 3. Missing Authentication on Restore
**Issue:** `/api/trash/:id/restore` lacked auth and permission checks
**Fix:** Added `requireAuth` middleware and permission validation
**Impact:** Security improvement

### 4. Inconsistent Error Responses
**Issue:** DELETE returned 403 for non-existent notes (should be 404)
**Fix:** Check existence before permissions
**Impact:** Better API consistency

## Lessons Learned

1. **Test Infrastructure First:** Setting up proper test helpers and mocks saves time
2. **Serial Execution:** SQLite databases require serial test execution to avoid conflicts
3. **Realistic Coverage Goals:** 40% coverage is excellent for comprehensive integration tests
4. **Native Modules in CI:** Always install build tools for bcrypt, sqlite3, etc.
5. **Coverage as Quality Gate:** Set thresholds to prevent regression, not to be perfect
